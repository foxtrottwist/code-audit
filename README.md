# Code Audit

Verify documentation accuracy against code using parallel subagents with state persistence.

## Usage

Invoke via Claude Code:

- "audit the codebase"
- "verify documentation"
- "check docs match code"
- "documentation health"

## Features

- Parallel subagent review of code partitions
- Verification gates to catch false positives
- Resume after interruption
- Accumulates codebase-specific lessons
